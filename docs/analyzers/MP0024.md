# MP0024

Calls Process.Start or creates ProcessStartInfo inside a module; use context.Shell for command interception, secret masking, and cancellation.

| Property         | Value                   |
| ---------------- | ----------------------- |
| Category         | Usage                   |
| Default severity | Warning                 |
| Availability     | Public analyzer package |

## Configure severity[​](#configure-severity "Direct link to Configure severity")

.editorconfig

```
dotnet_diagnostic.MP0024.severity = warning
```

Use `none` to disable the rule, or `silent`, `suggestion`, `warning`, or `error` to change its severity.

## Suppress a specific occurrence[​](#suppress-a-specific-occurrence "Direct link to Suppress a specific occurrence")

```
#pragma warning disable MP0024

// Code that intentionally violates MP0024.

#pragma warning restore MP0024
```
