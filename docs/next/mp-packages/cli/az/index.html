az CLI reference

ModularPipelines.Azure provides strongly typed access to the az CLI.

Executable prerequisite​

This package does not install the az executable. Install it separately and ensure az is available on PATH.

Follow the executable's official documentation for installation instructions.

Package installation​

dotnet add package ModularPipelines.Azure

Resolve the service with context.Tools.Az. Projects using C# 13 or another .NET language can use context.Tools.Get<ModularPipelines.Azure.Services.IAz>() instead.

Module example​

using ModularPipelines;
using ModularPipelines.Azure.Options;

public class RunCommandModule : Module<CommandResult>
{
    protected override async Task<CommandResult> ExecuteAsync(
        IModuleContext context,
        CancellationToken cancellationToken)
    {
        return await context.Tools.Az.Account.ListAsync(
            new AzAccountListOptions(),
            cancellationToken: cancellationToken);
    }
}
