## Migrating callers[​](#migrating-callers "Direct link to Migrating callers")

After automated regeneration, initialize inherited options on the selected command record. Reflection that uses `DeclaredOnly` must include the base class. Equivalent pnpm options are generated once; a command that changes an option's arity or aliases keeps its own replacement property. Shared pnpm reporter enums use the base-options name rather than a separate type for every command.

Yarn's `Cwd` renders as `yarn --cwd <directory> <command>`. Berry rejects this setting after most command paths, so it is the only setting added before Yarn subcommands. Set `Json` or `Immutable` on the command that documents it.

npm configuration controls render after the command with equals-separated values. Boolean configuration uses explicit `true`/`false`; `Color` accepts the strings `true`, `false`, or `always`. `Ca` and `Noproxy` accept repeated values. Proxy URLs retain secret metadata because they may include credentials; certificate/config file paths are paths, not credential contents. pnpm `Color` uses `CliOptionValue` for a bare switch or an attached explicit value.

The npm/npx API migration is owned by #5962 / #6054. This audit changes the merged scraper source independently and does not replace that migration's generated output. Automated output PRs must build/test the affected package solutions and pass coverage/freshness checks. There are no handwritten generated-file changes or generated-package API baselines in this audit.
