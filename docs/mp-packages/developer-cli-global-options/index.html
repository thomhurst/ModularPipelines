Global options in developer and infrastructure CLIs

This audit covers Git, Terraform, the .NET SDK, Go, the .NET nbgv tool, Cargo, Packer, and Vault from issue #5709. It consolidates the completed tool-specific changes and no-change dispositions as of 13 October 2026. AWS, Azure, Gcloud, Helm, kubectl, Docker, and other Cobra tools are tracked separately. See also the specialist CLI audit.

Versions below identify captured help used by the audit, not minimum supported versions or a promise that every installed release accepts every property. Command help, root execution settings, root information actions, and runtime-host arguments have different scopes. A switch repeated in several commands is not sufficient evidence of universal inheritance.

Reuse these model/generator helpers after tool-specific parsing; the tools do not share one root-help grammar. Generated options and CLI references remain generator-owned. Git's handwritten ownership is the documented exception, not a generated API shim.

Caller migration and contract details​

Use each package guide for its full API and generated CLI reference:

  • Git: use ChangeDirectories for repeated root directories and Configuration for ordered KeyValue entries. Root GitDirectory and BareRepository remain distinct from command-local reporting and clone flags. Migrate GitBaseOptions.GitDir and .Bare to those root names.
  • Terraform: set Chdir; remove equivalent manual -chdir arguments. Paths with spaces remain one value without shell quotes.
  • .NET SDK: set inherited Diagnostics; keep command verbosity and runtime-host options in their documented scope.
  • Go: replace command-local C/UpperC directory properties with WorkingDirectory. Keep test LowerC and terminal Args unchanged.
  • nbgv: no global migration is required. Keep command-local Project and the cloud build-number Version value.
  • Cargo: replace command-specific color enums with CargoColor; preserve counted verbosity and repeated configuration entries.
  • Packer: existing MachineReadable initializers now use inheritance. Explicit Color/Write false values render instead of being omitted; ConfigType takes a string and OnError takes the CLI policy value.
  • Vault: restored multiline options remain on applicable commands, retaining aliases, operands, and repetition.

Reflection that uses DeclaredOnly must include inherited properties where settings moved to base records. Command and version entry points remain available; help/version actions must not become configuration on every invocation. Check the installed CLI version before selecting newer execution settings.

Secret metadata masks Git configuration values, Cargo configuration overrides, and Vault credential values and authentication operands in command logs. Vault certificate/key file paths remain visible. Git ConfigEnv names environment variables without placing their secret contents in arguments. Log masking does not remove values from the operating system's process arguments; see the package guides for the supported credential-handling patterns.
