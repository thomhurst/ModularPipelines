# Documentation brand assets

The mark forms an M from connected modules, using mint and deep teal to match
the documentation palette. The navbar keeps its accessible live-text wordmark.

`modular-pipelines-master.png` is the original transparent artwork generated with
the built-in image generation tool. The production exports in `static/img/` are:

- `modular-pipelines-icon.png`: 512 px reusable icon.
- `modular-pipelines-logo.png`: 128 px navbar mark.
- `modular-pipelines-favicon.png`: 64 px PNG favicon.
- `favicon.ico`: 16, 32, 48, and 64 px favicon images.

Exports preserve alpha and use high-quality bicubic resampling.

## Generation prompt

```text
Use case: logo-brand
Asset type: production logo icon for the Modular Pipelines documentation website, also used as a tiny browser favicon.
Primary request: Design a distinctive minimal geometric M monogram built from a connected modular pipeline. Two upright stems and a clear central descending/ascending chevron make a strong unmistakable capital M silhouette. The ends and central joint subtly feel like modular square nodes, integrated into the monogram rather than extra diagram details. Bold consistent-width strokes, carefully balanced geometric proportions, lightly rounded exterior corners, generous negative space. One cohesive compact mark.
Color palette: predominantly mint teal #80d1c5 with one restrained deep teal #14776f module accent. Fits the website's dark blue slate #203e4a navbar and pale #edf3f6 canvas. The mint silhouette must be clear on dark backgrounds.
Style: refined flat vector-like developer-tool identity, precise clean edges, no gradients, no 3D, no shadows, no thin lines, no cubes, no separate floating dots, no decorative background, no border or enclosing badge.
Composition: square 1024x1024 canvas, centered symbol occupying approximately 88 percent of the width and height with equal small padding. Transparent background with real alpha transparency. Single icon only, no presentation sheet, no mockup, no text or wordmark, no watermark. Prioritize recognizability at 16px and 32px.
```
