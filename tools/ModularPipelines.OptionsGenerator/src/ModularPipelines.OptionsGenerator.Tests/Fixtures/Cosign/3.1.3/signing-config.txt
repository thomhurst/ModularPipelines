Tool for interacting with a Sigstore protobuf signing config

Usage:
cosign signing-config [command]

Available Commands:
create      Create a Sigstore protobuf signing config

Flags:
    -h, --help=false:
	help for signing-config

Global Flags:
      --output-file string   log output to a file
  -t, --timeout duration     timeout for commands (default 3m0s)
  -d, --verbose              log debug output

Use "cosign signing-config [command] --help" for more information about a command.
