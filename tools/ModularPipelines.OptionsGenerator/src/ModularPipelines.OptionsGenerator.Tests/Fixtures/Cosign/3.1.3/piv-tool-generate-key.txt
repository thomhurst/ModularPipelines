Generate a new signing key on the hardware token

Usage:
cosign piv-tool generate-key [flags]

Examples:
  # generate a key with default settings (slot 9c, always-touch policy)
  cosign piv-tool generate-key

  # generate a key in a specific slot with custom PIN and touch policies
  cosign piv-tool generate-key --slot 9c --pin-policy once --touch-policy always

Flags:
    -h, --help=false:
	help for generate-key

    --management-key='':
	management key, uses default if empty

    --pin-policy='':
	PIN policy for slot (never|once|always)

    --random-management-key=false:
	if set to true, generates a new random management key and deletes it after

    --slot='':
	Slot to use for generated key (authentication|signature|card-authentication|key-management)

    --touch-policy='':
	Touch policy for slot (never|always|cached)

Global Flags:
  -f, --no-input             skip warnings and confirmations
      --output-file string   log output to a file
  -t, --timeout duration     timeout for commands (default 3m0s)
  -d, --verbose              log debug output
