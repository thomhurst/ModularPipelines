Tools for interacting with a Sigstore protobuf trusted root

Usage:
cosign trusted-root [command]

Available Commands:
create      Create a Sigstore protobuf trusted root

Flags:
    -h, --help=false:
	help for trusted-root

Global Flags:
      --output-file string   log output to a file
  -t, --timeout duration     timeout for commands (default 3m0s)
  -d, --verbose              log debug output

Use "cosign trusted-root [command] --help" for more information about a command.
