List secrets

Description:
  

Usage:
  podman secret ls [options]

Aliases:
  ls, list

Examples:
  podman secret ls

Options:
  -f, --filter stringArray   Filter secret output
      --format string        Format secret output using Go template (default "{{range .}}{{.ID}}\t{{.Name}}\t{{.Driver}}\t{{.CreatedAt}}\t{{.UpdatedAt}}\n{{end -}}")
  -n, --noheading            Do not print headers
  -q, --quiet                Print secret IDs only
