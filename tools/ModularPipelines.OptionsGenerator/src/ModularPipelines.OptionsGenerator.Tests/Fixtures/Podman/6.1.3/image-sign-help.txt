Sign an image

Description:
  Create a signature file that can be used later to verify the image.

Usage:
  podman image sign [options] IMAGE [IMAGE...]

Examples:
  podman image sign --sign-by mykey imageID
  podman image sign --sign-by mykey --directory ./mykeydir imageID

Options:
  -a, --all                 Sign all the manifests of the multi-architecture image
      --authfile string     Path of the authentication file. Use REGISTRY_AUTH_FILE environment variable to override
      --cert-dir Pathname   Pathname of a directory containing TLS certificates and keys
  -d, --directory string    Define an alternate directory to store signatures
      --sign-by string      Name of the signing key
