Manage a project's sync windows

Usage:
  argocd proj windows [flags]
  argocd proj windows [command]

Examples:

#Add a sync window to a project
argocd proj windows add my-project \
--schedule "0 0 * * 1-5" \
--duration 3600 \
--prune

#Delete a sync window from a project
argocd proj windows delete <project-name> <window-id>

#List project sync windows
argocd proj windows list <project-name>

Available Commands:
  add                  Add a sync window to a project
  delete               Delete a sync window from a project. Requires ID which can be found by running "argocd proj windows list PROJECT"
  disable-manual-sync  Disable manual sync for a sync window
  disable-sync-overrun Disable sync overrun for a sync window
  enable-manual-sync   Enable manual sync for a sync window
  enable-sync-overrun  Enable sync overrun for a sync window
  list                 List project sync windows
  update               Update a project sync window
