
  Lists locally stored images.

Usage:
  buildah images [flags]

Examples:
  buildah images --all
  buildah images [imageName]
  buildah images --format '{{.ID}} {{.Name}} {{.Size}} {{.CreatedAtRaw}}'

Flags:
  -a, --all              show all images, including intermediate images from a build
      --digests          show digests
  -f, --filter strings   filter output based on conditions provided
      --format string    pretty-print images using a Go template
  -h, --help             help for images
      --history          display the image name history
      --json             output in JSON format
      --no-trunc         do not truncate output
  -n, --noheading        do not print column headings
  -q, --quiet            display only image IDs
