
Command
    az netappfiles account ad add : Add an active directory to the account.

Arguments
    --account-name --name -a -n                     [Required] : The name of the NetApp account.
    --resource-group -g                             [Required] : Name of resource group. You can
                                                                 configure the default group using
                                                                 `az configure --defaults
                                                                 group=<name>`.
    --active-directory-id                                      : Id of the Active Directory.
    --kdc-ip                                                   : Kdc server IP address for the
                                                                 active directory machine. This
                                                                 optional parameter is used only
                                                                 while creating kerberos volume.
    --no-wait                                                  : Do not wait for the long-running
                                                                 operation to finish.  Allowed
                                                                 values: 0, 1, f, false, n, no, t,
                                                                 true, y, yes.
