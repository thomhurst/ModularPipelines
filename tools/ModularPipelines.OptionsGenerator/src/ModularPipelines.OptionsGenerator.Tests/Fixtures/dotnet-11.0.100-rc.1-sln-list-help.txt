Description:
  List all projects in a solution file.

Usage:
  dotnet solution [<SLN_FILE>] list [options]

Arguments:
  <SLN_FILE>  The solution file to operate on. If not specified, the command will search the current directory for one. [default: C:\work\]

Options:
  --solution-folders  Display solution folder paths. [default: False]
  -?, -h, --help      Show command line help.
